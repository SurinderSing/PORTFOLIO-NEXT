# Memory Bank - Project Brief

## Project Overview
This repository contains the Next.js 14 web application for **Surinder Singh's Developer Portfolio & Admin Control Center**.
The project serves as a dynamic showcase of Surinder's expertise in React, Next.js, and dynamic AI application design. It features dynamic experiences, portfolio projects, skills matrix, contact system, and an administrative control center backed by Supabase PostgreSQL.

## Goals & Scope
- **Core Goal:** Provide a responsive, high-performance, and visually premium portfolio site to attract recruitment targets and technical partners.
- **Dynamic Data Goal:** Full database dynamism for all portfolio attributes, personal data, resume timelines, and skills via Supabase.
- **Admin Management:** Dedicated `/admin` dashboard allowing authorized administrators (`profiles.role = 'ADMIN'`) to update data in real-time.
- **Future Scale:** Open and maintainable database architecture for upcoming Blog, Stories, and Commenting modules.

## Project Scope Exclusions
- **No Unit Tests:** Writing, executing, or configuring unit tests is explicitly out of scope per developer instructions.
- **No CI/CD Configurations:** Automation pipelines or integration testing check workflows are out of scope.
