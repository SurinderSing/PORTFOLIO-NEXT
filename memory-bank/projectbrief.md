# Memory Bank - Project Brief

## Project Overview
This repository contains the Next.js 14 web application for **Surinder Singh's Developer Portfolio**.
The project serves as a showcase of Surinder's expertise in React, Next.js, and dynamic AI application design. It features sections detailing professional experience, projects gallery representations, and a formspree-validated email contact interface.

## Goals & Scope
- **Core Goal:** Provide a responsive, high-performance, and visually premium portfolio site to attract recruitment targets and technical partners.
- **Dynamic Migration Goal:** Future integration of Supabase to support dynamic, database-backed portfolio fields, experiences, and messages history database without maintaining a separate backend service.
- **AI Readiness:** Enable automated AI coding agents to onboard instantly and perform coding assignments in the codebase safely and confidently.

## Project Scope Exclusions
- **No Unit Tests:** Writing, executing, or configuring unit tests is explicitly out of scope per developer instructions.
- **No CI/CD Configurations:** Automation pipelines or integration testing check workflows are out of scope.
- **Static Assets Scope:** All portfolio metadata (experience dates, school names, project titles) remains hardcoded in page structures until the Supabase transition is initiated.
